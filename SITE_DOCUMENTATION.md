## 🏠 Обзор сайта

**Название:** ExpoLand Group  
**Тип:** Корпоративный сайт выставочной компании  
**CMS:** Grav 1.7.48  
**Язык:** Русский

### Основные разделы:
- **Главная** — презентация компании и услуг
- **О компании** — информация о компании, партнеры, отзывы, сертификаты
- **Услуги** — описание услуг по разработке и строительству стендов
- **Портфолио** — галерея реализованных проектов
- **Контакты** — контактная информация и форма связи
- **Отправить заявку** — форма для запроса коммерческого предложения

## 📄 Типы страниц и шаблоны

### 1. **Default** (Обычная страница)
- **Шаблон:** `default.html.twig`
- **Использование:** Стандартные информационные страницы
- **Примеры:** Главная, "О нас", описания услуг

### 2. **Portfolio** (Страница портфолио)
- **Шаблон:** `portfolio.html.twig`
- **Blueprint:** `portfolio-item.yaml`
- **Использование:** Главная страница портфолио с фильтрацией
- **Функционал:**
  - Автоматический сбор проектов из раздела "Портфолио" и "Услуги"
  - Фильтрация по типам стендов
  - Модальное окно для просмотра галерей
  - Адаптивная сетка карточек проектов

### 3. **Portfolio Item** (Элемент портфолио)
- **Шаблон:** `portfolio-item.html.twig`
- **Blueprint:** `portfolio-item.yaml`
- **Использование:** Отдельная страница проекта
- **Функционал:**
  - Отображение метаданных проекта
  - Галерея фотографий с настройками отображения
  - Lightbox для просмотра изображений
  - Кнопка возврата к портфолио

### 4. **Stand Page** (Страница типа стенда)
- **Шаблон:** `stand-page.html.twig`
- **Blueprint:** `stand-page.yaml`
- **Использование:** Страницы типов стендов (Типовые, Нестандартные, Эксклюзивные)
- **Функционал:**
  - Галерея примеров работ
  - Автоматическое определение типа стенда по slug страницы
  - Ссылка на полное портфолио

### 5. **Form** (Страница с формой)
- **Шаблон:** `form.html.twig`
- **Использование:** Страницы с формами обратной связи
- **Примеры:** "Отправить заявку", "Форма связи"

### 6. **Contacts** (Контакты)
- **Шаблон:** `contacts.html.twig`
- **Blueprint:** `contacts.yaml`
- **Использование:** Страница контактов с управляемой информацией
- **Функционал:**
  - Управление телефонами, email, адресом
  - Социальные сети
  - Яндекс карта с координатами

### 7. **Certificates** (Сертификаты)
- **Шаблон:** `certificates.html.twig`
- **Blueprint:** `certificates.yaml`
- **Использование:** Страница с сертификатами компании
- **Функционал:** Галерея сертификатов с названиями и описаниями

### 8. **Partners** (Партнеры)
- **Шаблон:** `partners.html.twig`
- **Blueprint:** `partners.yaml`
- **Использование:** Страница клиентов и партнеров
- **Функционал:** Список партнеров с логотипами и ссылками

### 9. **Reviews** (Отзывы)
- **Шаблон:** `reviews.html.twig`
- **Blueprint:** `reviews.yaml`
- **Использование:** Страница отзывов клиентов
- **Функционал:** Список отзывов с фотографиями

### 📋 Portfolio Item (Элемент портфолио)

**Blueprint:** `user/blueprints/pages/portfolio-item.yaml`

#### Вкладка "CONTENT" (Контент):
- **Заголовок** — название проекта
- **Содержимое** — описание проекта (Markdown)
- **Page Media** — медиафайлы страницы

#### Вкладка "Метаданные проекта":
- **Тип стенда** (обязательно) — выбор из списка:
  - Типовой
  - Нестандартный
  - Эксклюзивный
- **Площадь застройки** (обязательно) — например: "36 м²"
- **Название выставки** (обязательно) — название мероприятия
- **Название компании** (обязательно) — компания-клиент
- **Год проекта** — год реализации

#### Вкладка "Галерея проекта":
- **Фотографии стенда** — список фотографий:
  - **Описание фотографии** — краткое описание
  - **Загрузить изображение** — файл (до 10MB, JPG/PNG/GIF/WebP)
  - **Главная фотография** — отметка основной фото
  - **Альтернативный текст** — для доступности
- **Настройки галереи:**
  - **Тип отображения:**
    - Сетка (по умолчанию)
    - Слайдер
    - Масонри-сетка
    - Список
  - **Количество фотографий в ряду** — 2, 3 или 4 (для сетки)
  - **Показывать подписи** — включить/отключить

#### Вкладка "OPTIONS":
- **Published** — опубликована ли страница
- **Date** — дата публикации
- **Категории** — для фильтрации
- **Теги** — для поиска

## 🖼️ Портфолио и галереи

### Система портфолио

Портфолио работает как единая система, объединяющая проекты из двух источников:

1. **Раздел "Портфолио"** (`/portfolio`) — отдельные страницы проектов
2. **Раздел "Услуги"** (`/uslugi/razrabotka-stendov`) — примеры работ по типам стендов

### Автоматическая синхронизация

- Проекты из **Портфолио** автоматически появляются в соответствующих разделах **Услуг**
- Проекты из **Услуг** автоматически появляются в общем **Портфолио**
- Фильтрация происходит автоматически по типу стенда

### Функционал страницы портфолио

#### Фильтры:
- **Все проекты** — показать все
- **Типовые стенды** — только типовые
- **Нестандартные стенды** — только нестандартные
- **Эксклюзивные стенды** — только эксклюзивные

#### Карточка проекта:
- **Главное изображение** — первая фотография проекта
- **Счетчик изображений** — если фотографий больше одной
- **Название проекта**
- **Метаданные:**
  - Тип стенда (с цветовой индикацией)
  - Площадь застройки
  - Название выставки
  - Клиент (компания)
  - Год проекта
- **Описание проекта**

#### Модальное окно галереи:
- Открывается по клику на изображение
- Навигация стрелками (← →)
- Поддержка клавиатуры (Escape, стрелки влево/вправо)
- Счетчик изображений (например: "3 / 10")
- Подписи к фотографиям

### Типы отображения галереи (для Portfolio Item)

1. **Сетка** — упорядоченная сетка фотографий
   - Настройка: 2, 3 или 4 колонки
2. **Слайдер** — горизонтальная прокрутка
3. **Масонри-сетка** — динамическая сетка разной высоты
4. **Список** — вертикальный список с крупными превью

### Технические требования к изображениям

- **Форматы:** JPG, PNG, GIF, WebP
- **Максимальный размер:**
  - Портфолио: 10MB
  - Услуги: 8MB
- **Рекомендуемое разрешение:** от 1200x800px
- **Пропорции:** 4:3 или 16:9 (рекомендуется)

### Множественные изображения

Каждый проект может содержать:
- **Несколько фотографий** (до 20)
- **Главная фотография** — помечается специально
- **Подписи** — для каждой фотографии
- **Альтернативный текст** — для доступности

## 📝 Формы обратной связи

### 1. Форма "Отправить заявку"

**URL:** `/otpravit-zayavku`  
**Шаблон:** `form.html.twig`

#### Поля формы:
- **Ваше имя** (обязательно)
- **Компания** (необязательно)
- **Телефон** (обязательно)
- **Email** (обязательно)
- **Услуга** (обязательно) — выбор из списка:
  - Разработка и строительство выставочных стендов
  - Дизайн выставочных стендов
  - Полный выставочный сервис
- **Бюджет проекта** (обязательно)
- **Описание проекта** (обязательно) — многострочное поле
- **Прикрепить файлы** (необязательно):
  - До 10 файлов
  - Максимальный размер: 32MB на файл
  - Форматы: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, изображения, архивы, TXT
- **Согласие на обработку персональных данных** (обязательно)

#### Обработка формы:
- **Email отправка:**
  - Получатели: `expoland@mail.ru`, `stand@expoland-group.ru`
  - Тема: `[Заявка] Новая заявка с сайта`
  - Вложения: прикрепленные файлы
  - HTML формат
- **Сохранение:**
  - Файлы сохраняются в `user-data://forms/submissions`
  - Формат: `inquiry-YYYYMMDD-HHmmss-u.txt`
- **Перенаправление:** на страницу благодарности

---

### 2. Форма "Форма связи"

#### Поля формы:

- **Email** (обязательно)
- **Телефон** (необязательно)
- **Тема обращения** (обязательно) — выбор из списка:
  - Общая информация
  - Запрос коммерческого предложения
  - Консультация
  - Партнёрство
  - Жалоба
  - Другое
- **Сообщение** (обязательно) — многострочное поле
- **Согласие на обработку персональных данных** (обязательно)

#### Обработка формы:
- **Email отправка:**
  - Получатели: `expoland@mail.ru`, `stand@expoland-group.ru`
  - Тема: `[Контакт] [Тема обращения]`
  - Текстовый формат
- **Сохранение:**
  - Файлы сохраняются в `user-data://forms/submissions`
  - Формат: `contact-YYYYMMDD-HHmmss-u.txt`

- `01.` — первый уровень
- `02.` — второй уровень
- и т.д.

### Видимость страниц

- **visible: true** — страница видна в меню
- **visible: false** — страница скрыта из меню (но доступна по прямой ссылке)

Указывается в frontmatter страницы:
```yaml
---
```

---

## 🆘 Решение проблем

### Изображения не отображаются

1. Проверьте права доступа к папке `images/`
2. Очистите кэш: `bin/grav clearcache`
3. Проверьте формат файла (должен быть JPG, PNG, GIF или WebP)

### Форма не отправляется

1. Проверьте настройки Email плагина
2. Проверьте права на запись в `user-data/forms/`
3. Проверьте логи: `logs/grav.log`

### Проекты не появляются в портфолио

1. Убедитесь, что страница опубликована (`Published: Yes`)
2. Проверьте, что указан тип стенда
3. Очистите кэш
4. Проверьте, что есть хотя бы одна фотография в галерее

### Админ-панель не открывается

1. Проверьте права доступа к папке `user/`
2. Проверьте версию PHP (должна быть 7.3.6+)
3. Проверьте логи ошибок PHP
